# Arsenal
Catalogue des outils des bâtisseurs du web.

## Installation
1. `npm install`
2. Créer un fichier `.env` avec `ADMIN_PASSWORD=votre_mot_de_passe_fort`.
3. `npm run dev`

## Déploiement
Le projet est prêt pour un déploiement Next.js en mode standalone.
Assurez-vous que la variable d'environnement `ADMIN_PASSWORD` est configurée sur votre environnement de production.
